Cobble Spark integrates [Cobble](https://github.com/cobble-project/cobble) with
[Apache Spark®](https://github.com/apache/spark), with the goal of providing
distributed reads and writes over consistent snapshots through Spark SQL and
the DataFrame API.

## Status

Cobble Spark is under active development. The initial project structure targets Spark 3.3 with Scala 2.12.
